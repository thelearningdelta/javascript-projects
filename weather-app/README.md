# Steps to get Openweather API key
- Get the wheather api from OPenweathermap and set in `script.js`
file on line 2 under "".
- Link to get Openweather map API key - [here](https://openweathermap.org/)

## Steps to Setup in development

- Download the javascript-projects repo and goto to the weatherapp via filemanager or
open in vscode editor.
- Download the liveserver extension from extension manager.
- Set the api key after getting from website like said above.
- Open live server in bottom of editor and open in browser.

- Another way to get see projecy is download the repo and goto the
project weather app and open script.js file in any editor see the API key.
- Open the index.html in browser. yeah that works :)
